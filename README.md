# e-Portfolio ของ [ชนิตพล ภูเวียง]

เว็บไซต์แฟ้มสะสมผลงาน (e-Portfolio) สร้างด้วย HTML, CSS และ JavaScript เผยแพร่ผ่าน GitHub Pages

**เว็บไซต์:** https://[chanitpol].github.io/[repository]/

## เนื้อหาในเว็บไซต์

- เกี่ยวกับฉัน: แนะนำตัวและเป้าหมาย
- ทักษะ: สิ่งที่เรียนรู้และใช้งานได้
- ผลงาน: ผลงานที่ภูมิใจ พร้อมลิงก์เปิดดู
- ติดต่อ: อีเมลและ GitHub

## ผลงานโค้ด

| ผลงาน | คำอธิบาย | ลิงก์ |
|---|---|---|
| เครื่องคำนวณ BMI | รับน้ำหนักและส่วนสูง แล้วคำนวณ BMI พร้อมบอกช่วงเกณฑ์ ใช้ HTML, CSS, JavaScript | [projects/bmi.html](projects/bmi.html) |

## โครงสร้างโฟลเดอร์

```
├── index.html        หน้าหลัก
├── README.md         ไฟล์นี้
├── images/           รูปภาพ (เช่น profile.jpg)
└── projects/
    └── bmi.html      ผลงานโค้ด
```

## เครื่องมือที่ใช้

HTML, CSS, JavaScript, Git, GitHub Pages

## สิ่งที่ได้เรียนรู้

เขียนสรุปสั้น ๆ ว่าทำโปรเจกต์นี้แล้วได้เรียนรู้อะไร และอยากปรับปรุงอะไรต่อ
